Backtesting

The backtest engine replays historical fixtures in strict chronological order. For each match it predicts using only data available before kickoff (Elo updated after each result, form from prior matches only) — so there is no data leakage. Run it from the CLI over a historical fixture set: 

python -m backtest.run --start 2025-01-01 --end 2026-10-01 --leagues "Bundesliga,Premier League"

(CLI runner is provided as backtest/run.py. It needs an API key and historical coverage for the chosen leagues.)
